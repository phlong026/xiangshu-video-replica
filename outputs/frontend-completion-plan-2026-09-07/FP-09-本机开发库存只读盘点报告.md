## 2. 盘点口径

人物版本以 `character_versions` 为主表；已发布的七视图以 `character_assets.is_published_selection = 1` 为准。拼合图来源按以下顺序判定：

1. 读取 `character_versions.publication_snapshot_json.generation_source`；
2. 该字段缺失时，读取发布快照中的 `contact_sheet_asset_id`，再使用对应 `assets.metadata_json.generation_source`；
3. 两处均缺失、JSON 无效或关联资产不存在时单列为“拼合图来源未知”，不推断为真实资产。

切片来源独立核对：从每张批准资产的 `metadata_json.generated_asset_id` 找到原生成资产，再读取其 `metadata_json.view_content_source`。字段缺失时必须记为“切片来源未知”，不能用拼合图的 `generation_source` 代替。

引用关系包括数据库声明的外键和 JSON 冻结快照。外键分别统计 `character_assets`、`character_generation_tasks`、`character_reference_selections`、`character_sheet_tasks` 和 `project_main_characters`；`versions.payload_json` 解析为 JSON 后递归检查是否包含完全相同的版本 ID，不使用子串推断。`PRAGMA foreign_key_check` 结果为 0 条违规。
