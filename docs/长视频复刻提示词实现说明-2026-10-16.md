# 长视频复刻提示词实现说明（2026-10-16）

> 性质：功能实现说明。范围：独立新入口「长视频复刻提示词」——4–180 秒源视频
> → 一段完整复刻提示词 + 逐句口播文案 + 全片摘要，展示 + 一键复制，不接站内生成。
> 与既有复刻链路（4–15 秒拆解 → 分镜卡 → 逐段生成）完全解耦。

## 一、产品口径

- 入口：工作台侧栏「创作」组新增「长视频复刻提示词」（`StudioPage: "long-replica"`），Web 与桌面共用同一页面。
- 时长：4–180 秒（+0.1 秒舍入容差），文件 ≤600 MB，仅收 MP4 / MOV 视频。
- 产物：`replica-prompt.v1`——`replica_prompt`（一段完整提示词）、`spoken_script`（逐句口播带时间戳）、`summary`（主题/视觉风格/节奏/镜头语言/色调五字段）。**不产出分镜表**。
- 下游：本期只展示与复制；站内生成契约仍是 ≤15 秒，长视频复刻生成属「Segment Chain 片段链」后续方案（见 docs/长视频生成方案研究-2026-09-22.md）。

## 二、上传通道（新 purpose，不动既有 15 秒门禁）

| 位置 | 改动 |
| --- | --- |
| `server/app/media_routes.py` | `UploadIntentRequest.purpose` Literal 增加 `"replica_prompt"` |
| `server/app/media.py` | 新常量 `MAX_REPLICA_PROMPT_DURATION_SECONDS=180.0`、`REPLICA_PROMPT_MAX_UPLOAD_BYTES=600MB`；`validate_duration` 改为按 purpose 分流（replica→15s / replica_prompt→180s / script→不限） |
| 完成校验 | >200MB 的对象走新增 `_probe_oversized_upload_completion`：流式落临时文件做哈希/探测/抽帧，verified 副本用 `put_file` 流式上传，绝不整载内存（≤200MB 的原路径不变） |

600MB 的依据：180 秒手机实拍 H.264 约 17Mbps≈380MB，200MB 装不下。
本地存储通道（`/api/assets/local-objects/*`）仍按 200MB 拒绝——该通道仅供内部/开发，
客户生产为 COS 直传；如需放开另行评估。

## 三、任务族 replica_prompt（仿 script_from_audio，不动 analysis_tasks）

- 迁移 `20261016T1000_replica_prompt_tasks.py`：`replica_prompt_tasks` 表
  （PENDING/RUNNING/SUCCEEDED/FAILED + attempt/locked_by/locked_until 租约 +
  result_version_id/error/retryable/request_id），活跃任务 partial unique
  `(project_id, asset_id)`。**v1 无 attempt 历史表**，失败原因保留在任务行。
- `server/app/replica_prompt.py`：enqueue（活跃去重 + `accept_operation(service="analysis", units=1)` 预扣）/
  acquire（租约 **25 分钟**）/ prepare（签名 URL **30 分钟**——必须活过整个调用）/
  perform / complete（versions kind=`replica_prompt` + `finish_source(succeeded=True)` 同事务 CAS）/ fail / cancel。
- 超时参数：`VIDEO_REPLICA_REPLICA_PROMPT_TIMEOUT_SECONDS`（默认 900 秒，配置惯例 `*_ENV`）。
  15 秒源片实测单次调用 71–91 秒，按比例 180 秒可达 15 分钟量级，租约必须覆盖全程。
- Worker：`generation_worker.py` PG lane 与 SQLite lane 各加一步领取执行
  （付费调用在事务外，与拆解同一纪律）；平台成本记录复用 `video_analysis_768p` 科目。
- 计费：v1 与拆解同价（`analysis` 目录每次 1 单位，钱包/报表零改动）；
  `units` 参数已就位，切按秒计价只需改目录与入队单位。

## 四、提示词模板与解析

- 模板 `server/app/prompt_rules/replica_prompt.txt`：只记录源片事实——
  一段可直接投喂视频生成模型的完整中文提示词 + 逐句口播（不编造听不清的内容）+
  五字段摘要；明确禁止分镜表/列表/分段编号，禁止出现「复刻/原片」字样。
- `ApilioGemini.analyze_replica_prompt()` / `FakeGemini.analyze_replica_prompt()`；
  解析 `parse_replica_prompt_payload` 刻意宽松（键与类型对即可，多余键不拒）：
  本链路没有分镜卡的时间轴合同，唯一必须可靠的是提示词本身。
- Provider 构造复用 `get_video_analysis_provider`（新增 `transport` 参数注入长超时），
  apilio 配置（key/模型/备选）与拆解共用。
