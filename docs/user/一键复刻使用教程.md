# 一键复刻：第一次设置，之后直接使用

1. 在首页推荐或爆款视频列表点「一键复刻爆款」。首次使用自动打开三步教程；关掉就不会自动再弹，在视频详情点「使用教程」可重看。
2. 第一次走某条路线时选择默认素材。AI 视频选择已发布的人物版本；数字人口播选择同一人物下就绪的视频分身和已试听确认的声音。默认设置仅在本设备、当前账号保存，在视频详情可单独更换。
3. 继续后按视频时长自动分流：
   - 4–30 秒（含 30 秒）：AI 导入、拆解、准备首帧和生成提示词；确认成片报价后开始生成。
   - 超过 30 秒：提取参考视频中的口播，用已授权的默认分身和声音重新演绎；不会克隆原作者或照搬其画面。转写文本可编辑，修改后重新报价，确认后生成。
4. 在「任务中心」查看成片进度。拆解、首帧和转写可能产生积分；保存默认素材不是付费授权。最终成片仍需确认报价。

## 关闭、刷新后继续口播复刻

- 提取后的文案和你的修改会保存在本设备、当前账号与当前视频下。关闭弹窗或刷新后，再次进入同一视频可继续编辑，不会用原转写覆盖改稿；更换素材也会保留文案。重新打开后需要重新获取并确认报价。
- 网络中断、暂未取得提交结果时，系统会保留原请求，锁定文案与素材。再次进入后获取报价，点击「继续核对原口播任务」，会恢复同一次请求，不会另建一条任务。
- 服务端已受理时，会显示保存的任务编号，可直接去任务中心查看。需要制作另一版时，先点击「新建一个口播版本」，再编辑文案、重新确认报价。
- 请勿在任务结果待核对期间清除浏览器本地数据。浏览器无法保存草稿时会提示，请先复制文案；无法保存任务恢复信息时不会提交生成。

**遇到问题：** 不足 4 秒、时长未知或来源不可用不会自动提交。缺少分身或声音，先到人物库创建并确认。长视频没有清晰语音时可以手填文案；已经完成的转写，下次打开同一视频会优先恢复，不重复转写。请只使用有权使用的参考内容。
