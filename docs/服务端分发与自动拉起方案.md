# 服务端分发与自动拉起方案

> 决策日期：2026-08-15
> 关联：CRITICAL-1（Windows 打包桌面端无后端自动拉起机制，发布阻断项）
> 状态：Tauri 拉起逻辑已实现（跨平台，cargo check 通过）；**PyInstaller 打包服务端与 Windows 实机验证待办**

## 1. 问题

Tauri 桌面端是纯前端壳，访问 `http://127.0.0.1:8000` 的 FastAPI。打包后的 NSIS 只装前端壳，不装 Python/uvicorn。员工安装后启动桌面端 → 后端无监听 → 全线不可用。

## 2. 已实现（本批次）

### Tauri 侧自动拉起（`client/src-tauri/src/lib.rs`）

桌面端启动时：

1. `local_api_ready()` 用 TCP 探测 `127.0.0.1:8000`，确认后端是否已在运行；
2. 若未运行，从环境变量 `VIDEO_REPLICA_BOOT_COMMAND` 或默认脚本（`start-backend.bat` / `start-backend.sh`，与可执行文件同目录，随 NSIS `bundle.resources` 打包）拉取启动命令并 `spawn`；
3. 子进程句柄存入 `app.manage(BackendProcess)`；
4. `RunEvent::Exit` 时 `kill` 子进程，避免残留。

启动脚本（`client/src-tauri/resources/`）默认按开发布局用 `uv` 启动 uvicorn + worker；**分发形态变化时通过环境变量 `VIDEO_REPLICA_SERVER_CMD` / `VIDEO_REPLICA_WORKER_CMD` 覆盖命令**。

### 回环安全约束

- FastAPI 中间件强制所有请求来自本机回环（非回环 403）；
- 启动脚本要求 `VIDEO_REPLICA_DB_PATH` / `VIDEO_REPLICA_SETTINGS_KEY` 已设置，否则退出。

## 3. 推荐分发方案（待执行）

**推荐：PyInstaller 将服务端打包为单目录可执行，作为 sidecar 随 NSIS 分发。**

理由：

- 员工机无需预装 Python/uv（当前 skill 一键包用 WinGet 装 Python 的方案，对桌面端同样可行但更重）；
- PyInstaller 单目录产物跨平台（Windows/macOS 均可），便于 macOS 先验证；
- Tauri 拉起逻辑已按"任意可执行命令"设计，`VIDEO_REPLICA_SERVER_CMD` 指向 PyInstaller 产物即可，无需改 Rust。

实施步骤：

1. 用 PyInstaller 打包 `server/app`（含 uvicorn、SDK、alembic）为单目录 `video-replica-backend/`；
2. 生成 `start-backend.bat` 指向该目录的可执行（替换当前默认 `uv` 命令）；
3. Windows x64 实机验证：安装 → 启动 → 自动拉起后端 → `/health` ok → 完整工作流；
4. 若不愿引入 PyInstaller，备选：NSIS 安装时用 WinGet 装 Python 3.11 + 复制 `server/` + 写启动脚本（复用 skill 安装思路）。
