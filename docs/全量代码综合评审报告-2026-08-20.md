## 3. 本轮发现并修复

### High

1. **真实生成结果归档与账务结算矛盾**
   - 问题：Worker 和归档重试固定写本地盘，但 Metaso 成功结算要求 `cos://` 成片。
   - 处理：Worker、归档重试统一使用已配置的 `StorageAdapter`；COS 配置有效时成片归档 COS，本地回退只保留给开发环境。

2. **服务器本地对象 URL 指向访问者的 localhost**
   - 问题：本地存储上传、下载和人物缓存 URL 硬编码为 `127.0.0.1:8000`。
   - 处理：服务器设置合法 `PUBLIC_BASE_URL` 后统一生成公网 HTTPS URL；未设置时才保留桌面开发回退。

3. **上传解析依赖存在已知漏洞**
   - 问题：`python-multipart==0.0.20` 被 `pip-audit` 命中 6 个已知漏洞，包含高危拒绝服务类问题，与[官方安全公告](https://github.com/Kludex/python-multipart/security/advisories)一致。
   - 处理：升级并锁定为官方发布的 [`0.0.31`](https://pypi.org/project/python-multipart/0.0.31/)，再重跑上传和全量测试。2026-08-20 通过临时隔离工具命令 `uvx pip-audit --path server/.venv/lib/python3.13/site-packages` 复扫，结果为 `No known vulnerabilities found`；本地非 PyPI 项目包 `video-replica-api` 按工具规则跳过。

4. **既有账号升级和 Gate 1 账号缺少内部钱包**
   - 问题：内部计费迁移创建了钱包表，但没有为迁移前的用户补零余额钱包；Gate 1 又绕过标准账号创建路径，导致创建生成批次时抛出账务不变量错误。
   - 处理：新增 `024_wallet_backfill` 数据修复迁移；Gate 1 使用带完整 `CHARGE` 流水的隔离测试余额；生产生成入口遇到账务损坏时记录上下文并返回结构化错误，仍保持 fail-closed，不在请求中偷偷补余额。

5. **Nginx 按原部署权限无法读取管理端**
   - 问题：发布树使用 `0750`，Nginx Worker 无法穿过目录读取 `client/dist`；Basic Auth 文件又是 `root:root 0600`，Worker 无法读取口令文件。
   - 处理：不含密钥的发布树改为 `0755`；环境、数据和密钥继续保留在发布树外；口令文件改为 `root:www-data 0640`，并在手册中要求非 Ubuntu 环境先确认实际 Nginx Worker 用户。

### Medium

1. **Web 生产构建可能误连 localhost**：未设 `VITE_API_BASE_URL` 时，HTTPS Web 生产页现在回退到页面同源；桌面和开发构建继续连本机 API。
2. **Nginx 默认会导致大文件 `413` 和长 Provider 调用 `504`**：增加 64 MB 请求上限、310 秒代理超时、HTTP 跳转 HTTPS 和基础安全响应头。
3. **人物生成占用 API 事件循环**：同步 Provider/图像工作改在 Starlette 线程池执行，不阻塞健康检查和其他请求。
4. **首次部署时 SQLite 父目录可能不可写**：手册现在显式以 `video-replica` 用户创建 `/var/lib/video-replica`。
5. **缺失主机名的 HTTPS origin 可通过格式校验**：媒体公网 URL 和 ZPay 部署配置现在都拒绝空 hostname。

## 4. 仍保留的风险和边界

1. **单机 SQLite**：只能部署一个 API 和一个 Worker，不能水平扩展；多实例前需迁移 PostgreSQL 和明确任务队列。
2. **生产尚未代码强制 COS**：运维必须在开放真实任务前将业务存储设为 COS 并通过诊断；中期任务是在服务端启动和保存配置时禁止生产 `local`。
3. **管理列表容量**：后端支持 `limit/offset`，但当前管理页只取首批 50 条，没有分页控件；内部 P0 初期可接受，账号或订单超过 50 后会漏看。
4. **可观测和异机灾备**：现有 systemd journal 和本机 SQLite 日备份，没有外部告警、指标面板和已验收的异机备份。
5. **真实第三方证据缺口**：ZPay 最低额充值、COS put/head/get/delete、Provider 成功/失败和 `RESERVE -> SETTLE/RELEASE` 尚未在正式域名联合验收。
6. **测试依赖弃用警告**：当前 FastAPI/Starlette `TestClient` 会报 `httpx` 迁移警告，不影响运行结果，但应在后续依赖升级时处理。
