1. 模块顺序 M1→M9 线性推进；后模块依赖前模块产物，不并行。
2. 每模块收尾动作固定：专项 pytest 全绿 → ruff/mypy 绿 → Codex S 级评审（读全量 diff，可查仓库）→ 发现项逐条闭环（P0/P1 必须修复后复审，P2/P3 可登记）→ commit（显式路径 add）。

- 评审锚点：方案 §3.1（DDL、谓词集合、三个独立状态集合定义）。

### M2 编排驱动核心
- 范围：入队（幂等键用户作用域 + request_hash，友好性在途检查）；`acquire_replica_pipeline_task`（轮询谓词、排除挂起行、attempt++）；推进器（§3.2 转换表实现、`next_poll_at` 退避 30s→5min 封顶、操作键 `pipeline:{id}:{stage}:{retry_no}`）；三类期限（24h 执行 / 30min 无进展 / 重试预算 2，计时按有效运行时长排除挂起）；失租迟到提交拒绝（attempt/locked_by 校验）。
- 验收：转换表逐行单测（合法迁移/非法迁移拒绝）；崩溃恢复复用同 retry_no（操作键找回）；假时钟触发三类期限；attempt 违例被拒；挂起行不被领取。
- 评审锚点：方案 §3.2 / §3.2.3 / §3.3。

### M3 五阶段执行器
- 范围：IMPORTING（复用 purpose=replica 导入，键混入 pipeline_id）、ANALYZING（复用拆解入队与在途规则）、SCRIPT_VERSIONING 桥接（从本次 analysis 幂等建 script version，`source=no_narration` 兜空文案）、FIRST_FRAMING（冻结人物绑定、开场帧抽取、候选质检强制 `quality.passed`、自动确认入口记录 `AUTO_PIPELINE`）、COMPOSING（进程内编译，`preserve` 策略，冲突码→FAILED 出口）；跨归属在途任务冲突拒绝（不含归属素材指纹判定）。
- 验收：每阶段五路用例（成功 / 确定性失败→retry_no 原子递增 / 冲突拒绝 / 无口播 / 候选全拒→FAILED）；图像/视频供应商全桩；自动确认入口不复用 `HUMAN_CONFIRMATION` 人工 confirm。
- 评审锚点：方案 §2（原语事实）/ §3.4。

### M4 确认点资金闸门
- 范围：报价冻结（`generation_price_quote` → quote_token + quote_snapshot 含金额上限/档位/名额数/总秒数/产物指纹）；confirm 原子事务（非锁定读→锁 projects→锁 pipeline→持锁重验→validate_quote→时长能力三查→锁 prompt→建批次（键派生 pipeline id）→资金预占→GENERATING）；cancel；三栏费用快照组装（已结算/仍预占/新增）。
- 验收：300s 过期拒绝并要求重展；token/金额/指纹任一不符拒绝；并发 confirm 行锁下单次生效；确认后价格目录变更不重计价；建批次后崩溃重放返回既有结果；cancel 与 confirm/expire 竞争同一行锁裁决。
- 评审锚点：方案 §4.1 / §4.2 / §4.3。

### M5 生成域映射与重生成
- 范围：批次终态→pipeline 映射（含 uncertain 冻结禁止新付费提交）；交付谓词实现（covered/deliverable 两计数、768P 可交付=`SUCCEEDED+DIRECT`）；SETTLED 产物恢复观察轮询（仅免费恢复事件，无付费动作）；重生成受理事务（迁 GENERATING 触发唯一索引裁决资格、钱包敞口复查、替代受理持锁三态处置旧任务）；DELIVERED_PARTIAL 接受动作；替代链三处校验（领取/过期恢复/迟到完成）。
- 验收：映射矩阵用例（全成功/部分失败/NEEDS_ATTENTION/全失败结清/全覆盖不可交付）；重生成资格冲突 409 且预占未发生；替代三态（终态标记/恢复中拒绝延后/失租归一历史终态）；替代成功后 pipeline 实际可达 DELIVERED；免费恢复×付费替代交错时旧任务不再被领取、迟到结果不改替代链、计费不重复收口。
- 评审锚点：方案 §3.2.1 / §3.2.2 / §5.1 / §5.1.1。

### M6 止付 fencing 与全局锁序改造（全仓最高风险）
- 范围：提交许可谓词（推进态∪NEEDS_REVIEW-无uncertain 白名单；DRAINING 排除）；发送意图记录（父锁内签发+消费原子）+ 三域付费提交点接入（generation/image/analysis）；自动任务归属 metadata；自动+手动入队统一项目行锁互斥（含 `media.py:persist_upload_completion` 锁序前移改造）；统一撤销事务（接管/删项目/期限→DRAINING，清挂起屏障、挂起产物降级历史）；独立过期扫描（AWAIT_CONFIRM 72h，恒定计时）。
- 验收：挂起/开关关/DRAINING/uncertain 四种止付逐域验证（不提交供应商、保持 PENDING、释放租约、不计费不耗预算）；已受理调用不受影响（查询/归档/结算/对账照常）；自动×手动并发入队真库测试（项目锁串行化）；上传完成×直接入队交错真库测试（锁序无死锁）；撤销→DRAINING→收口→终态；接管后挂起产物降级不发布不触发下游；手动链路零行为变化（回归断言）。
- 评审锚点：方案 §5.3 / §6；S 级全量 diff 精读（触碰既有域最多）。
