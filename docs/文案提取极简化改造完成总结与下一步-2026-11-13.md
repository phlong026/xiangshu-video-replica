### 2. 新的提取链路（改造后）

```
粘贴链接（douyidou/元宝解析）或上传素材
  → 服务端导入取媒体（抖音/小红书音频优先；视频号视频→服务端 ffmpeg 抽音轨）
  → 云存储归档
  → ASR 转写（按秒计费，仅真实转写者付）
  → 任务 result.text 直接下发正文
  → 文案工坊改写（按次）→ 复刻
```

- 用户粘贴的链接**不进前端爆款列表**（`category='链接导入'` 不可上架）；爆款库供给收归管理端粘贴导入入口（已上线）
- 旧桌面客户端兼容：任务正文直读自然兼容；**发起新提取**的 claim 入口收到 410 升级引导（`VIRAL_COPY_CLAIM_RETIRED` / `VIRAL_COPY_UPLOAD_RETIRED` 两个壳）
- 「提取记录」页保留：数据源改为本人 SUCCEEDED 任务流水按视频聚合，正文恒可复用
- `request_json.viral_source` 保留为内容经营报表的爆款归因记录（不参与任何资格判定）
