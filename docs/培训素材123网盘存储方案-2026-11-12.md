> 状态：方案已获批（用户 2026-11-12 拍板），本文档为 Codex A 级评审对象；评审闭环后才开实施。
> 承载分支：`feat/materials-training-library-20261101`（未合 main，其中培训迁移未发布、可直接修改）。

## 0. 摘要与拍板记录

培训素材库（管理端上传、客户只读）的存储从「COS/本地双车道」改为 **123 网盘唯一车道**。
用户拍板（2026-11-12）：

1. 只用 123 网盘，不用本地、不用 COS（接受单供应商风险，换取容量成本与免运维）；
2. Office 文档（word/excel/ppt）预览走**微软 Office Online Viewer 嵌入**；
3. 123 网盘账号**已开通**：123 云盘会员 + 开发者权益包（OpenAPI/直链管理），有 clientID/clientSecret 与直链鉴权密钥。

功能扩展：格式白名单扩展到视频/音频/图片/文档四组；**按格式分组**（kind 四组）；
**上传必填标签、按标签筛选**；**软件内预览**（视频/音频/图片/PDF 原生，Office 文档走
Office Online）；管理端可查看/复制直链。

## 1. 背景与范围

### 1.1 现状

分支已实现（未合 main）：`training_materials` 表 + 管理端四段契约上传/编辑/上下架/软删 +
客户只读列表与签名下载；存储复用 `get_media_storage`（COS/本地双车道）。本方案将该域的
存储车道整体替换为 123 网盘，并叠加格式/标签/预览需求。

### 1.2 范围

- **在范围内**：培训素材域的上传、存储、直链签发、预览、标签体系；123 网盘 HTTP 客户端；
  供应商配置登记；`provider_settings` CHECK 放宽迁移（同批修复 yuanbao 遗留问题，见 §7.4）。
- **不在范围内**：全局 `active_storage_provider` 与 `get_media_storage` 闸门不动（参考视频/
  人物图/首帧等业务仍走 COS/本地）；客户成片交付链路不动；123 网盘视频转码（M3U8）本期
  不接（权益包含该能力，后续按播放体验决定是否启用）；管理端「彻底删除」（远端删对象）
  暂不做，软删语义保持。

## 2. 123 网盘 OpenAPI 事实与前置条件

Base `https://open-api.123pan.com`；除鉴权接口外均带请求头 `Platform: open_platform` +
`Authorization: Bearer {accessToken}`。

| 能力 | 接口 | 说明 |
| --- | --- | --- |
| 鉴权 | `POST /api/v1/access_token` | body: clientID/clientSecret → accessToken + 过期时间；进程内缓存、到期前重取 |
| 上传（秒传/分块） | `POST /upload/v2/file/create` → PUT 分块到预签名 URL → `POST /upload/v2/file/upload_complete_v2` | create 带 parentFileID/filename/size/etag(文件 md5)；命中秒传直接返回 fileID；完成可能异步，`GET /upload/v2/file/upload_async_result` 轮询 |
| 小文件直传 | `POST /upload/v2/file/single/create` | 单请求直传通道；200MB 内是否可用以 spike 实测为准，可用则作为优先路径 |
| 取下载链接 | `GET /download/v2/file/download_info?fileID=` | 返回 DownloadUrl（带有效期）；作为直链不可用时的回退通道 |
| 直链 | `vip.123pan.com/direct/{uid}/{fileID}/{文件名}` + `?sign=..&time=..` | 防盗链签名 `md5(uid:sign_secret:time)`（time=到期时间戳）；拼接顺序以官方 FAQ 为准，spike 核验 |

**红线（官方明示）**：禁止调用非 OpenAPI 接口列表中的其余非公开接口，违者封号。客户端只
实现上表接口；任何「网页端抓包接口」一律不接。

**Spike 验证清单**（第 1 步，真实账号、探针文件即传即删、凭据只走环境变量）：

1. access_token 获取与过期语义；2. v2 上传（分块与 single 直传路径、字段细节、etag 要求）；
3. download_info 返回结构与链接有效期；4. 直链模板+签名是否可播放、是否支持 Range（拖动）；
5. 直链防盗链 `time` 到期行为；6. OpenAPI 限流阈值（QPS）。

## 3. 架构设计

### 3.1 总体数据流

```
管理端上传（multipart, 四段契约, Idempotency-Key）
  → 流式落临时文件（sha256+md5 单遍计算）
  → Pan123Client.upload_file（create→分块 PUT→complete→轮询确认）
  → 业务事务 INSERT（remote_file_id=123pan fileID）+ 审计
  → 客户播放/下载：POST /api/training-materials/{id}/download-url
      → 服务端取直链（内存 TTL 缓存）→ 返回 {"url", "expires_at"}（响应形状不变）
  → <video>/<audio>/<img>/Office Online iframe 直接消费直链
```

### 3.2 新模块 `server/app/pan123_client.py`

```python
class Pan123Client:
    def __init__(self, config: Mapping[str, str], *, opener=None, timeout_seconds: int = 30): ...
    def upload_file(self, remote_name: str, path: Path, *, content_type: str) -> Pan123File
        # 返回 Pan123File(file_id, size)；upload_file 内部完成秒传判定/分块/complete/轮询
    def resolve_download(self, file_id: str, *, filename: str, ttl_seconds: int = 1800) -> tuple[str, int]
        # 返回 (签名直链 URL, 到期 epoch)；直链模板不可用时回退 download_info
    def delete_object(self, file_id: str) -> None   # 本期仅测试与连接测试使用
    def check_readiness(self) -> None               # 连接测试用：轻量探测

class Pan123AuthError(...); class Pan123Unavailable(...)  # 域化错误 → 路由层 503
def signed_direct_link(uid: str, sign_secret: str, file_id: str, filename: str, ttl_seconds: int) -> tuple[str, int]
```

- **HTTP 纪律**：全部走 `external_calls.recorded_urlopen`（`provider="pan123"`、显式
  timeout、`read_limit`、`endpoint_from_url`），`opener` 参数留测试注入缝隙；调用日志的
  URL 脱敏由 `redact_url` 自动覆盖 sign/time 等查询参数。
- **凭据**：来自 `SettingsRepository.load_provider_config("pan123")`（Fernet 加密存储）。
- **进程级缓存**：accessToken 缓存（模块级，到期前 60s 重取）；直链缓存（模块级 dict，
  key=remote_file_id，TTL=到期前 5 分钟失效重签）。多 worker 各自缓存，可接受（低频运营域）。

## 6. 安全与红线对照

1. **凭据**：client_secret/sign_secret 仅存 Fernet 加密 `provider_settings`；客户端永不可见；
   管理端回显走 `mask_config` 掩码（子串命中 `secret` 自动生效）。
2. **日志**：`recorded_urlopen` + `redact_url` 自动剥离 sign/token 等查询参数；禁止打印
   accessToken 与直链全文。
3. **封号红线**：只调 OpenAPI 列表内接口（§2 表），不接网页端抓包接口。
4. **直链泄露边界**：直链为「持有即访问」的公开 URL（30 分钟防盗链签名）；客户侧仍走
   download-url 按需签发，管理端直链仅运营复制分享用；用户已拍板接受。
5. **上传纪律**：四段写契约、Idempotency-Key + sha256 内容指纹、审计 `training_material.*`
   全部保持；200MB 流式上限不变（123pan 分块通道天然支持）。

## 7. 风险与既有问题

### 7.1 微软 Office Online 依赖（用户拍板接受）

国内访问 officeapps 服务稳定性一般；文件大小有上限（MB 级）；直链 URL 会暴露给微软服务器。
降级路径：预览失败/超限 → 常驻下载按钮。

### 7.2 直链不可即时撤销

30 分钟有效期内的直链无法踢线撤销（原本地车道 epoch 机制随车道删除而移除）。兜底：短时效
+ 签发需登录 + download-url 逐次重签。

### 7.3 账号单点

123 网盘账号被封/欠费 = 素材全部不可播。用户拍板接受；软删素材对象保留在网盘（可恢复）；
探针测试每日可巡检通道健康度（复用连接测试）。

### 7.4 ⚠️ 同批修复的既有隐患：yuanbao 不在 provider_settings CHECK

`ProviderName` 含 `yuanbao` 且元宝凭据走 `provider_settings`
（`viral_wechat_link.py:452` load），但 DB CHECK 白名单最后一次放宽是
`20260928T1200_customer_email_password_reset`（+ses），**不含 yuanbao**——元宝功能已合
main 但未上生产，部署后管理端保存元宝配置将撞 CHECK 报 500。本次 `pan123` 放宽迁移同批把
`yuanbao` 纳入白名单（约束 drop+recreate 本就同点），并在 upgrade 无需数据回填。

### 7.5 其他

- OpenAPI QPS 限制：直链服务端缓存 + 上传串行（运营低频），风险低；
- 孤儿对象：上传成功但业务事务失败时 123pan 留无引用文件（唯一文件名、无污染），本期不做
  GC，依赖直链流量不计量未引用文件（无流量则无成本）；
- 图片网格直连 CDN 的流量成本：lazy loading 控制（§5.2）。
