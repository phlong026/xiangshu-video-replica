# 短视频复刻桌面端开发说明：技术评审记录

> 独立评审基线：短视频复刻桌面端开发任务书 V1.1
> 当前增量版本：V1.2
> 评审日期：2026-08-13
> 评审方式：代码/规格审查 + 架构审查，两路独立只读评审
> 本文档仅记录评审，不替代主任务书

## 1. 初审结论

- 代码/规格审查：REQUEST CHANGES；
- 架构审查：WATCH；
- 无 CRITICAL；
- 初审发现 3 个 HIGH、若干 MEDIUM/LOW。

主要风险：

1. 创建 H3 请求超时后可能重复付费；
2. 人物库缺参考素材与授权字段；
3. 输出时长缺确定规则；
4. 生成输入快照和异步恢复字段不足；
5. 归档失败状态不闭合；
6. 声音能力可能被误当作隐性 P0 硬指标；
7. P0 第三方视觉配置过度泛化；
8. cURL 示例不可复制执行；
9. RBAC、业务审计和 FakeProvider 测试不完整；
10. METASO 查询接口仍未确认。

## 2. 已完成修订

- 增加 SUBMISSION_UNCERTAIN，创建结果不确定时禁止自动重提；
- 增加 idempotency_key + request_hash 一致性规则；
- 增加 GenerationInputSnapshot；
- 明确 output_duration_seconds 的取值、覆盖、锁定和快照规则；
- P0 预置 generation_mode=I2V；
- 增加轮询租约、归档状态和 ExternalCallLog；
- 增加 CharacterReferenceAsset、授权范围、附件和有效期；
- 增加 employee/admin/auditor 最小 RBAC；
- 增加人物库和授权业务 API；
- 增加 AuditLog 和审计读取接口；
- 增加 FakeProvider、契约测试和真实 Provider 的分层验收；
- 扩充 Gemini 拆解必填/可选结构；
- V1.1 曾将声音拆分为预览与硬门槛两种方案；该设计已被 V1.2 的明确产品决定替代；
- 把 METASO 查询 SOURCE_PENDING 提升为 M0/M4 硬门禁；
- 修复 cURL 示例；
- 第三方视觉通用设置在 P0 通过 feature flag 隐藏。

## 3. 复审结论

- 架构复审：CLEAR，无架构阻断项；
- 代码/规格复审：APPROVE，无 HIGH/MEDIUM 阻断项；
- 本地结构检查：Markdown 围栏成对、章节连续、JSON 示例可解析；
- 密钥检查：主任务书和评审记录中未发现真实 mk-/sk- 密钥；
- 外部链接：本次列出的核心资料均已打开核对，Nano Banana 页面曾有一次临时连接失败，重试为 HTTP 200。

V1.1 独立评审结论：APPROVE。架构状态：CLEAR。

## 4. V1.2 增量修订

根据最新产品决定，V1.2 已完成以下范围收缩：

- P0 不实现独立音频上传、声音库、声音克隆、TTS、混音、音轨替换或口型同步；
- P0 只保留 H3 返回 MP4 中的原生音轨；
- 原口播稿和自定义稿只通过 Prompt 引导 H3；
- 删除 Voice Provider、voice_id、声音设置和声音任务；
- 数据库统一改为 SQLite；
- 增加 SQLite WAL、foreign_keys、busy_timeout、单节点、短事务、原子任务租约、备份和恢复约束；
- 增加原生音轨存在性与可播放性检查；
- 增加 SQLite 并发、迁移、备份和恢复测试。
- 生成数量从固定选项改为员工输入的正整数；
- 增加管理员可配置的单批次上限和 H3 并发上限；
- 增加批次进度条、状态计数、单任务阶段、轮询和重开恢复；
- 对供应商没有提供百分比的 QUEUED/RUNNING 阶段使用动态等待条，不显示虚假精确进度。

本次是对已通过 V1.1 的范围收缩和数据库替换，已完成全文一致性、结构、示例与密钥检查；没有宣称重新执行两路独立评审。

## 5. 仍未解除的外部门禁

以下不是文档缺陷，而是开发和上线前必须取得的外部证据：

- METASO H3 正式任务查询、结果获取、取消/回调说明；
- Apilio 当前令牌组对三个模型名和字段的真实支持；
- Nano Banana Pro 2K 的实际模型别名；
- Gemini json_schema 的当前模型组支持情况；
- H3 真实 I2V 结果包含可播放原生音轨；
- 已暴露的 METASO 示例密钥完成吊销和轮换。

在这些门禁解除前，只能把主任务书标记为“开发可启动、Provider 闭环待验收”，不能标记为生产就绪。
