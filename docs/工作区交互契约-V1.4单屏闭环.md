## 1. 工作区就绪状态机（冻结）

### 1.1 三段就绪结构

readiness 聚合层（P0-01 `useWorkspaceReadiness`）输出三段结构：

```ts
type WorkspaceReadiness = {
  content: boolean;   // 内容就绪（标签页①）
  people: boolean;    // 人物就绪（标签页②）
  launch: boolean;    // 生成就绪（标签页③）
  valid: boolean;     // 三段全部就绪
  missing: ReadonlyArray<ReadinessMissingItem>;
};

type ReadinessMissingItem = {
  key: ReadinessKey;          // 见 1.2 表格
  label: string;              // 中文缺失说明（见 1.2 表格）
  tab: "content" | "people" | "launch";  // 「前往处理」跳转目标标签页
};
```

### 1.2 七项前置条件判定表

| # | key | 就绪条件（与现有代码语义逐条对齐） | 缺失中文标签 | 归属标签页 | 现有代码依据 |
| --- | --- | --- | --- | --- | --- |
| 1 | `shotCardVersion` | `shotCardVersionId` 非空 **且** `shotCardsDirty === false` **且** `isSaving === false`（镜头卡片存在已保存版本且当前无脏编辑/保存中） | 镜头卡片尚未保存 | content | `AnalysisWorkspace.tsx` stage-block 02/03：`shotCardVersionId` 门禁与 `isSaving \|\| shotCardsDirty` 只读传递 |
| 2 | `scriptVersion` | 口播稿存在已保存版本（`scriptVersion !== null` **且** 非脏稿；stale 稿视为"有版本但需重存"，计入缺失） | 口播稿尚未保存 | content | `GenerationComposer` 第 1 段：`scriptVersion`/`scriptStale` 状态；任务 13 的"口播稿未保存禁止编译 Prompt"fail-closed |
| 3 | `characterVersion` | 角色版本快照存在（`characterSelection?.character_version_id` 非空，**或** legacy `character_id` 非空） | 未选择角色版本 | people | `AnalysisWorkspace` stage-block 01："先选择角色版本"门禁 |
| 4 | `sourceFrame` | 源画面选择存在（`sourceFrameSelection !== null`） | 未选择源画面 | people | `SourceFrameSelection` 渲染门禁 |
| 5 | `characterReference` | 人物参考选择存在（`characterReferenceSelection !== null`）；**legacy 豁免**：`legacyCharacterSelected === true`（绑定的是旧 `character_id` 路径）时本项自动视为就绪 | 未确认人物参考 | people | `AnalysisWorkspace`：`!legacyCharacterSelected && character_version_id && sourceFrameSelection` 条件渲染；V1.3 任务 11/12 决议 |
| 6 | `firstFrame` | 首帧选择存在且有效（`firstFrameSelection !== null` 且 payload 可读出 `first_frame_asset_id`） | 未确认首帧 | people | `AnalysisWorkspace` stage-block 03："确认置换首帧后可继续"门禁 |
| 7 | `promptLocked` | Prompt 存在 `LOCKED` 版本（`promptVersion` 存在、status === `LOCKED`、非 stale）**且** 生成参数合法：时长 4–15 秒整数、分辨率 ∈ {768P, 2K}、数量在 runtime limits `[min_quantity, max_quantity]` 内 **且** 参数与锁定快照一致（`output_duration_seconds`/`resolution`/`quantity` 匹配） | Prompt 未锁定或参数不一致 | launch | `GenerationComposer` L215-247 参数校验 + 服务端 `generation.py` `PROMPT_NOT_LOCKED`/`PROMPT_STALE`/`PROMPT_PARAMETERS_MISMATCH` fail-closed |

### 1.3 三段聚合规则

```
content = #1 shotCardVersion && #2 scriptVersion
people  = #3 characterVersion && #4 sourceFrame && #5 characterReference(含legacy豁免) && #6 firstFrame
launch  = #7 promptLocked
valid   = content && people && launch
```

- 缺失项按上表 `tab` 字段归组；缺失项模态（P0-02-05）逐项展示中文标签 + 「前往处理」。
- **不引入新的就绪语义**：七项条件与现有门禁/服务端校验一一对应，readiness 只是聚合展示层，不改变任何服务端 fail-closed 校验。
- busy 语义独立于 readiness：`isWorkspaceBusy`（generation busy + upstream busy 聚合）继续阻断导航与编辑，**不并入** readiness 计算（busy 是临时态，readiness 是持久态）。

### 1.4 现有 busy 聚合语义（保持不变，P0-01-02 行为锁定）

- `upstreamBusyCountsRef`：四源（character/source-frame/reference/first-frame）重入计数，`size > 0` 即 upstream busy；
- `isGenerationBusy`：GenerationComposer `busyAction` 非空；
- `isWorkspaceBusy = isGenerationBusy || isUpstreamBusy`，经 `onWorkspaceBusyChange` 上抛阻断壳层导航；
- 后续所有标签页组件必须复用同一聚合通道，**禁止在标签页内各自维护 busy**。

## 2. 标签页组件归属表（冻结）

### 2.1 三标签页归属

| 标签页 | key | 迁入内容 | 来源组件（现有代码位置） |
| --- | --- | --- | --- |
| ① 内容配置 | `content` | 镜头卡片编辑区（含 800ms 防抖自动保存、脏态计算、忙时只读）；口播稿编辑（ScriptEditor：原稿/自定义切换、显式保存、stale 提示、镜头映射列表） | `AnalysisWorkspace.tsx` stage-block 02（L628-681）；`GenerationComposer` 第 1 段（口播稿区） |
| ② 人物设定 | `people` | 角色版本卡片（侧栏弹层改常驻卡片）；源画面选择；人物参考；首帧（纵向流水线：角色 → 源画面 → 人物参考 → 首帧） | `AnalysisWorkspace` stage-block 01（L572-627）：`CharacterSelection`/`SourceFrameSelection`/`CharacterReferenceSelection`/`FirstFrameSelection` |
| ③ 生成设置 | `launch` | 冻结来源摘要；Prompt 编译/修订/锁定/差异（GenerationLauncher）；时长/分辨率/数量；付费提醒；「开始生成」主按钮 | `GenerationComposer` 第 0/2/3 段 |

### 2.2 组件改造边界

- **四个子组件（Character/SourceFrame/Reference/FirstFrame）内部不改**：仅改布局位置与外围包装，内部 props/行为/测试保持（P0-05-01 以"既有用例零修改通过"证明）。
- **GenerationComposer 拆分**（P0-02-01）：拆为 `ScriptEditor.tsx`（→ 标签页①）与 `GenerationLauncher.tsx`（→ 标签页③），共享 script/prompt 加载逻辑上移 `useGenerationDrafts` Hook；`GenerationComposer` 薄组合层临时保留至 P0-02-05 后删除；幂等恢复记录（`idempotencyStorageKey`）语义不变。
- **锁边界的 props 注入**：口播稿未保存时禁止编译 Prompt（fail-closed）拆分后由 `GenerationLauncher` 通过 props 接收 `scriptSaved: boolean` 注入。
- **`ProjectWorkflowSteps`**：工作区内停用（被标签页+就绪徽章替代）；组件文件保留（新建项目页仍使用）。
- **stale 级联清空链保持**：角色变 → 清源画面/参考/首帧；源画面变 → 清参考/首帧；参考变 → 清首帧（`handleCharacterSelectionChange` 等回调逻辑不变，仅改视觉呈现）。
- **`AnalysisWorkspace` 外层分支保持**：加载/错误/待拆解/重试分支不动，仅替换表单主体为标签页壳层。

## 3. 人工确认红线（冻结，压缩交互但不取消动作）

以下为 V1.3 任务 11/12/13 正式决议，V1.4 只减少点击次数：

| # | 红线 | 原因 | 压缩后的交互（冻结） |
| --- | --- | --- | --- |
| 1 | 人物参考必须人工确认后才落库 | 任务 12：自动建议不得冒充人工确认 | 推荐加载后默认勾选 1–2 张（身体/服装参考 + FRONT_FACE 身份图），用户单击"确认使用推荐参考"落库；可改选 1–4 张后确认；**推荐预览不落库不写审计** |
| 2 | 首帧必须人工确认 | 任务 12：置换结果需人工验收 | 候选生成完成自动预选第一张，用户单击"确认首帧"完成；历史版本与 stale 标记不变 |
| 3 | 首帧生成是付费调用，不得自动触发 | 成本控制 | 仅用户显式点击触发生成；进入页面/切标签页绝不自动调用 |
| 4 | 批次创建必须显式付费确认 | 任务 13/14：幂等与付费保护 | 编译→锁定→创建合并为一次「开始生成」点击；N>1 时展示付费提醒与预计费用；幂等键沿用任务 13 指纹语义 |
| 5 | legacy `character_id` 旧项目路径保留 | 任务 11/12 兼容决议 | legacy 路径在标签页②同等可用：人物参考项自动豁免（readiness #5），不显示缺失 |
| 6 | auditor 全程只读 | RBAC 决议 | 所有标签页/预填/主按钮在 `readOnly` 下禁用；预填逻辑在 `readOnly` 下不触发任何落库 |
