## 0. 使用规则

### 0.1 状态标记

| 标记 | 含义 |
| --- | --- |
| `[x]` | 已完成，且证据路径已填写 |
| `[~]` | 代码或局部 UI 已存在，但未达到本任务验收标准 |
| `[ ]` | 未开始或无可验证实现 |
| `[!]` | 依赖真实账号、外部资料或业务签字 |

### 0.2 开发纪律

继承 V1.3 纪律不变：

1. 写一个失败的回归/契约测试；
2. 用最小改动实现；
3. 跑目标测试；
4. 跑相关 lint、类型、格式、构建和安全检查；
5. 查看完整 diff，确认没有覆盖他人未提交改动；
6. 一个逻辑变更一个中文提交。

本次改造为纯前端 UX 重构，**不新增数据库迁移、不改变服务端 API 契约、不改变业务真源**。若实施中发现必须动服务端，单独开一个契约任务并回到本清单登记。

### 0.3 合规红线（不可违反）

以下门禁是 V1.3 任务 11/12/13 的正式决议，本次改造**只能减少点击次数，不能取消人工动作**：

| 红线 | 原因 | 允许的优化 |
| --- | --- | --- |
| 人物参考必须人工确认后才落库 | 任务 12：自动建议不得冒充人工确认 | 推荐项默认勾选，压缩为一次点击 |
| 首帧必须人工确认 | 任务 12：置换结果需人工验收 | 生成后自动预选最佳候选，一次点击确认 |
| 首帧生成是付费调用，不得自动触发 | 成本控制 | 一键触发，不得进入页面即调 |
| 批次创建必须显式付费确认 | 任务 13/14：幂等与付费保护 | 合并编译/锁定/创建为一次点击 |
| legacy `character_id` 旧项目路径保留 | 任务 11/12 兼容决议 | 旧路径在标签页布局中同等可用 |
| auditor 全程只读 | RBAC 决议 | 所有新组件保持只读边界 |

## 1. 改造范围与目标

### 1.1 改造对象

仅改造**项目工作区**（`AnalysisWorkspace` 及其下游组件），入口壳层（`App.tsx` 五入口导航）、人物库、任务记录、设置页不动。

### 1.2 目标动线

```
打开项目 → 工作区自动预填（角色/源画面候选/口播原稿）
  ↓
单屏三标签页：
  [① 内容配置]  镜头卡片(自动保存) + 口播稿
  [② 人物设定]  角色 + 源画面 + 人物参考 + 首帧（纵向一屏流水线）
  [③ 生成设置]  Prompt + 时长/分辨率/数量 + 主按钮
  ↓
点「开始生成」→ 就绪则自动 编译→锁定→创建批次 → 跳任务记录
              → 未就绪则弹缺失清单，逐项「前往处理」跳转标签页
```

### 1.3 成功度量

| 指标 | 现状 | 目标 |
| --- | --- | --- |
| 完成一次生成所需用户点击 | 9-12 次 | ≤4 次（选源画面特征、确认参考、确认首帧、开始生成） |
| 工作区内整屏切换/门禁阻塞 | 4 处条件渲染门禁 | 0 处（改为全部渲染+就绪聚合） |
| 编译→锁定→创建批次点击数 | 3 次 | 1 次 |
| 标签页切换状态丢失 | —（现状无标签页） | 0（keep-alive 不卸载） |
